# Roadmap

Easy Fill should stay small, local-first, and predictable. The roadmap below is ordered by how much each item can improve real-world usefulness and contributor momentum.

## Near term

- Expand Chinese alias coverage for internship, scholarship, graduate-school, and campus portal forms.
- Add real-world compatibility tests for Ant Design, Element Plus, and common custom select/date controls.
- Improve mapping explanations so users can understand why a field was matched.
- Add profile import/export for backup and device migration.

## Medium term

- Remember user-confirmed field mappings per domain.
- Add optional profile templates for student, job seeker, scholarship, and research application workflows.
- Provide a demo form page so new users can test the extension without using personal data.
- Add browser-store packaging notes and release checklist.

## Later

- Support Firefox if the Plasmo build and permissions model remain straightforward.
- Add optional redacted debug reports for compatibility issues.
- Explore community-maintained site adapters for popular school and recruiting systems.

## Non-goals

- No hosted backend for profile storage.
- No opaque automatic decisions that cannot be explained to users.
- No autofill for passwords, payment cards, verification codes, or other high-risk secrets.
